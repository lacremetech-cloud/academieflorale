# Médias — Académie Florale

Dépose ici les fichiers avec **exactement ces noms** (ou envoie-les-moi en pièce jointe et je les commit).
Une fois poussés, Vercel les sert automatiquement et les pages les affichent.

## Logos
| Fichier | Usage |
|---|---|
| `logo-orange.svg` (ou `.png`) | Logo principal (nav, fonds clairs) |
| `logo-blanc.svg` (ou `.png`) | Logo blanc (bande noire, footer) |
| `monogramme-af.svg` | Monogramme AF seul (favicon, petits espaces) |

## Recommandations
- Photos : format **portrait 3:4**, largeur ≥ 1200px, optimisées (< 400 Ko, JPG/WebP).
- Logos : **SVG** de préférence (net à toute taille), sinon PNG transparent ≥ 1000px.

## Pour systeme.io
Dans les blocs systeme.io, les images doivent être en **URL absolue**.
Utilise l'URL Vercel : `https://<ton-domaine-vercel>/assets/img/hero-sybile.jpg`
(ou uploade-les dans la bibliothèque média systeme.io et utilise ces URLs-là).
